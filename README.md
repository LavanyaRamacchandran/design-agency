# NEXA. — Digital Design Studio

A modern and responsive Design Agency landing page built with Next.js, React, TypeScript, and Tailwind CSS.

## Live Demo

https://design-agency-blond.vercel.app

## GitHub Repository

https://github.com/LavanyaRamacchandran/design-agency

## Features

- Modern responsive design
- Hero section with call-to-action buttons
- Services section with four service cards
- Portfolio section with project thumbnails
- Portfolio hover effects
- Responsive mobile navigation
- Contact form with basic validation
- Contact form success message
- Responsive desktop and mobile layouts
- SEO-friendly page metadata
- Smooth section navigation

## Setup Instructions

1. Clone the repository

git clone https://github.com/LavanyaRamacchandran/design-agency.git

2. Navigate to the project

cd design-agency

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Open the application

Visit http://localhost:3000

## Production Build

npm run build

The project has been tested with a successful production build.

## Assumptions

- The contact form demonstrates client-side validation and a success state. It does not send messages to a backend or email service.
- Portfolio images are used as visual project thumbnails for demonstration purposes.
- The implementation focuses on the assignment requirements while keeping the code simple and maintainable.
